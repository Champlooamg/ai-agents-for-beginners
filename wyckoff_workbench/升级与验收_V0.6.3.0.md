# 威科夫投研工作台 V0.6.3.0 升级与验收

日期：2026-10-09。基线：V0.6.2.1 独立副本。原版本文件未覆盖。

## 本版实现

- 新增“全市场观察”页和 `POST /api/fetch/tdx-market`。用户指定日期后，读取单个通达信盘后包，扫描包内可识别的沪深北普通A股代码；标准化快照与原始包分别留存。
- 按交易所统计代码表、有价行、无正收盘价行与来源最低有价行门槛。无正收盘价代码保留名称并标记状态unknown，不猜为停牌或退市。2022-05-06之前没有北交所文件的包明确显示沪深部分范围。
- 新增单日涨跌/平盘方向观察、交易所分布与全量代码CSV导出；显示未认证事项及候选/策略输出阻断原因。页面不会按单日涨幅、成交额或任意评分排出“投资标的”。
- 全市场包覆盖元数据、快照行数、无价证券名单、原始来源SHA和交易所范围由本机审计做一致性复核。旧版附件的列表型origin仍按原样处理，旧研究卡和事实复算不变。
- 原有威科夫范围保持不变：W-LPS-BU / W-SPRING-TEST仍须人工登记并经过测试；W-WEAKNESS仅用于风险观察。没有新增技术指标、形态战法、绩效或收益标签。

## 当前能力边界

上游说明将该HTTP盘后包作为沪深北单日全市场日线入口，并指出北交所日线走此路径；它仍然只是一个交易日的行情快照。包内代码与最低行数检查只做结构/明显残缺检测，不是交易所完整证券池认证。

本版没有多日全市场历史库、历史点时股票池、有效复权/公司行动、完整交易日历或ST/停复牌/涨跌幅限制历史。因此单日价格方向不是威科夫区间、测试、响应或市场阶段。自动候选扫描、买入触发价、卖出/失效价、短中期持有期限和策略卡仍为BLOCK；不生成标的推荐，也不表示策略无机会。

## 后续实施顺序

1. 验收可重复的多日沪深北历史行情、点时证券池、公司行动/复权与交易日历，并记录与独立清单的差异。
2. 冻结威科夫市场/个股背景、结构、测试、响应、失效、退出与超时规则；短期和中期窗口作为独立预登记假设。
3. 在不使用未来信息的情况下实现批量扫描和证据链；策略卡输出入场触发、价格口径、失效/退出、交易日持有上限、风险预算和未成交约束。
4. 完成T+1、涨跌停、费用、滑点和组合级成交评估，再依次通过项目定义的六道验证门及样本外检验。
5. 完成以上数据与方法闸口后，再评估可部署形态；本版没有券商接口或自动交易能力。
