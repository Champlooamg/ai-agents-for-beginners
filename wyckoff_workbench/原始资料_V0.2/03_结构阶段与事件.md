# 结构、阶段、事件与竞争假设

三大定律指导观察，价格循环组织背景，事件与响应检验解释。实时记录采用candidate/as_of/provisional，不宣称已知最终阶段或最后低点。

## 结构档案

每个structure_id记录周期、区间起点、支撑/阻力区域、形成依据、首次登记时间、revision_id、snapshot_id及标注者。边界须先于用它定义的突破/下破事件可得；新增边界从新版本可得时间起适用，不倒签。

记录前序上/下波的幅度、用时、量、净推进、收盘、重叠和截至当前的保持，按同一级别比较。转折确认方法和所需滞后必须登记；日线不能恢复唯一盘中路径。

主假设至少配一个可反驳竞争假设，例如吸筹／再派发、再吸筹／派发、供需改变／流动性稀薄。性质不明使用unknown。每项都写supports、opposes、confirm_if、invalidate_if、expiry，不能用最终盈亏重命名早期背景。

## 循环与分期

| 结构背景 | 重点观察 | 易误判处 |
|---|---|---|
| 潜在吸筹 | 原下跌停止、测试变化、相对改善、向上保持 | 低位横盘不认证吸筹；无Spring也可能测试 |
| 潜在再吸筹 | 上涨后整理中回撤/测试是否保持、后续推进 | 不能因为此前上涨排除派发 |
| 潜在派发 | 上涨停止、反弹弱化、向下推进与保持 | 高位横盘不认证派发；高潮不等于最终高点 |
| 潜在再派发 | 下跌中的反弹是否受阻、弱势是否恢复 | 反弹也可能转吸筹，保留竞争解释 |
| 上涨/下跌发展 | 离区间后的持续推进、回吐与新结构 | 阶段E不保证趋势持续 |

A—E分别关注原趋势停止、区间供需建立、关键测试、方向优势表达、区间外发展。它们不是强制发生的固定序列；四阶段循环与A—E是不同层次，不能拼成九阶段。阶段标签保留截至当时版本，不回填最终完美分期。

## 事件需要背景与响应

| 事件组 | 描述依据 | 不能直接推出 |
|---|---|---|
| PS/SC/AR/ST | 下跌中的停止线索、反弹、再测试及区间形成 | 最终底部、机构已吸筹 |
| SOS/Reaction/LPS/BU | 强势推进、反向响应、支撑测试和回到突破区域 | 涨停就是SOS、LPS必为最终低点 |
| Spring与测试 | 已登记支撑下破、收回、后续测试/响应 | 每个下影线都是Spring、必须有Spring才可上涨 |
| PSY/BC/AR/ST | 上涨中的供应/高潮、自动回落及再测试 | 最终顶部、主力全部出货 |
| UT/UTAD | 既有阻力上破失败与回到区间 | 每个上影线都是UTAD |
| SOW/LPSY | 下行推进、弱收盘/保持、反弹未恢复 | 能按镜像规则直接做空或按最高价退出 |
| Follow-through | 当前已发生的净推进/收盘/保持 | 未来必然延续、可无限延长等待 |

吸筹AR是自动反弹，派发AR是自动回落，字段必须写完整方向和背景。同名ST可能是不同性质的测试。SOS可以在区间内部表达；区间突破与随后保持另记，不强迫每次突破必然回测。

## 失效与修订

预登记支撑失守、收回失败、弱势扩大、强势被回吐、测试后无响应和等待届满等具体条件。触发后追加失效/超时，不将失败改叫第二次洗盘继续等。

若结构必须因新事实重建，保存旧记录和否定原因，新建structure_revision_id或新结构；已有候选仍按原版本追踪结果。结构冲突暂停新增多头执行候选，风险退出不受术语争论拖延。

首版采用隐藏未来的人工标注，保存标注分歧与复核记录。无法在同一历史前缀重复标注的定义不能进入效果比较；自动结构识别器尚未实现。

## V0.2行为优先与命名口径

按15先记位置、逐根/同级波事实、支持/反对及预期响应，再写事件和阶段。中性边界事实与Spring/UTAD等理论标签分开：B01在后续区间突破后命名Spring，B04可在下破失败/收回阶段命名候选，两者须有不同label_definition_version；不移动事件时间或覆盖先前判断。

吸收、衰竭、需求不足与交易限制都是待区分解释；高量小推进不能证明主力行动。停止线索先记原推进受阻，后续AR/ST/响应各自可得后再更新；高潮候选与最终顶底分开。未见后续响应只有截至当时的含义，等待窗口与否定参照在新增信息前冻结。
