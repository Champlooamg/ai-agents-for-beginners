# 现代量价表达工具与数据准入 · V0.2

威科夫2.0与量价指南提出更细的交易活动表达。本体系仅把这些工具登记为潜在供需研究仪器，核心仍是日线威科夫。当前全部disabled_data_and_validation_pending，不参与候选筛选、评分或订单。

## 最低数据与公式

| 工具 | 最低数据合同 | 允许表达与禁止推断 |
|---|---|---|
| 价位成交量分布VAP/VP | 同窗口真实交易价格、数量或供应商可靠价位量聚合；粒度、覆盖与重建方法可审计 | 描述价位活动量；日OHLC均匀分配只是代理，不能标真实VP、真实POC或机构成本 |
| POC/VA/HVN/LVN | 合格VP，固定分箱、锚点、窗口、并列与边界算法 | POC为最大量箱；并列处理冻结。VA按算法覆盖预定q成交量，不自动等于正态区间。节点是活动量事实，吸引或反转效应待研究 |
| 交易VWAP/锚定VWAP | 同窗口真实成交额与成交股数，币种/单位/场次一致，锚点当时可知 | sum(成交额元)/sum(股数)。日量额能得全场窗口平均成交价，不能得盘中轨迹；典型价×量另标proxy |
| 主动方向Delta/累计Delta | 可审计主动方向标记或报价匹配；报价同步、集合竞价、撤单/纠错/重复规则 | V_buy_initiated−V_sell_initiated，未知方向单列；累计起点冻结。不认证资金净流入、开平仓、机构身份 |
| Footprint/不平衡 | 合格方向数据按时间/价位聚合、分母与零值规则 | 描述已分类主动交易；斜向/同价算法和阈值待登记，不导入200/300/400%默认值 |

成交总量与主动方向差量是不同字段。阴阳K线、成交价处于上部/下部、软件红蓝颜色均不能单独证明主动方向。供应商推断标签注明estimated与算法，未分类记录不填零；所有交易同时有买卖双方，配对数量不能说明参与者人数或持仓动机。

成交额为零/缺失而量为正的数据不能计算VWAP；量×收盘不是成交额。已有本地数据的真实量额缺口未因此修复。a-stock优先接入次序、Yuanastock重要候选、QVeris目录发现角色依13保留，任何来源的付费或可获取状态不等于数据验收。

## 时间、窗口与图形

所有锚点、窗口、分箱与VA算法在当时版本内冻结。固定区间、可见区间、会话/复合分布是不同版本；不能拖动屏幕直到信号好看。POC、VA、VWAP的动态值须带as_of和最大依赖时间，不使用最终会话/最终结构值给早期决策。

TPO统计时间/出现次数，VP统计量，两者不混用；P/D/b轮廓不能直接命名吸筹/派发。70%与68.2%只可成为明确待研究覆盖选择，不能当80%到达概率或价格必走路径。日线无法恢复独一盘中先后，聚合不能改善本来不存在的顺序信息。

## 开启前的四步

1. 按11验收来源与用途，核对价位量/方向标签覆盖、单位、授权、历史可得时间、错误更正和交易日历。
2. 冻结算法并与原始成交复算；核对聚合量额守恒、分类量加未知量与总量一致、竞价及断流处理、未来追加不变性。
3. 先只记录工具值，不改变威科夫核心规则；参数和试验预算预登记，运行先过12闸口。
4. 通过06六道门才讨论具体研究用途升级；共享价量信息不得叠加为独立确认。

验收不足即data_blocked，不能为了“学会2.0”强行增加盘口复杂度。新增数据工具不意味着增加另一技术战法，也不产生自动交易权限。
