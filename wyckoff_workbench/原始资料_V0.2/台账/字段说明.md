# 八张研究台账与检查约束

UTF-8 CSV，逗号分列，含逗号/换行用双引号；ID列表用分号连接。空项是unknown，not_applicable明确写字面值。当前全表仅表头，没有真实候选、订单或结果。

| 台账 | 主键/关键关联 | 内容 |
|---|---|---|
| evidence.csv | evidence_id；canonical_key | 单事实、来源版本、可得时间依据、缺失状态与原始依赖；同源去重，修订追加不覆盖 |
| structures.csv | structure_id＋revision_id；snapshot_id | 边界/阶段当时版本、竞争假设、支持反对和修订 |
| shadow_events.csv | event_id；candidate_id/event_family_id | 仅多头路径状态；scenario限W-LPS-BU/W-SPRING-TEST及独立W-BASE |
| risk_events.csv | risk_event_id；结构/候选/订单 | W-WEAKNESS与独立风险处置；risk_state不是成交状态 |
| checklists.csv | check_record_id；结构/候选 | 全版/简化清单逐项状态、确认时间和未知 |
| experiments.csv | experiment_id；parent_id/trial_family_id | 所有定义/参数/分层尝试、时间切分、门槛与失败 |
| orders.csv | order_id；candidate_id/experiment_id | 模拟/观察订单、库存、成交结果和假设 |
| outcomes.csv | outcome_id；candidate_id/decision_record_id | 结果窗口与成熟时间、退出/截尾、表现来源 |

结构外键须指定revision_id，不用最新修订替代旧决策。candidate_id所属场景和底层事件族不变；同股重复候选按实验定义去重/归组。冻结record_sha256指独立研究卡文件，不对含自身哈希的行作循环哈希。

evidence的依赖不得成环；所有引用均可解析到来源/快照。source_available_at须有availability_basis；evidence_status使用02定义的枚举，缺失/不可用/确认零值/未知不可互换。修订填source_revision_id与supersedes_id，追加新行，不覆盖旧事实。check_status={observed,not_observed,unknown,not_applicable}；checklist_version指冻结清单，不把观测项数量转成概率。

order_mode={paper_simulation,observed}；fill_status={filled,partial,unfilled,unknown}。所有模拟订单填fill_model_version与assumption_flags，模拟未成交仍unfilled。卖出量不超过老仓可卖减已冻结量，今日新仓不作为普通A股当日可卖库存；申报单位按当时规则。

多头状态按04校验，弱势risk_state独立校验。风险请求可指向尚无交易的候选；有持仓时必须连至库存/订单记录，无库存不可虚构减仓。已有真实执行制度与权限不由本包修改。

outcomes里的价格路径评价与成交收益分开，未成交只可记路径观察，不能记假交易收益。标签未成熟/期末未退出/观察缺失与实际亏损分开；成熟结果不得回填早期证据或特征。弱势风险效果用风险记录和对应订单/暴露报告，不借多头成功率度量。

experiment状态planned_incomplete/frozen/running/closed/invalidated；六道门逐项另存结果。未冻结实验的描述卡允许留空experiment_id，明确不具备效果比较资格。所有结果与错误修订追加，保留supersedes_id和原因。

每次归档人工检查：主外键/版本、合法时间、冻结哈希、共享证据、状态、成熟标签、库存/订单模型、定义与阈值试验。当前没有自动语义校验程序，CSV结构正确不证明内容合规。

## V0.2四张附表（基础八表不变）

新增表当前只有表头。普通空字段为unknown；分母、源时点或依赖不足不得补零。ID引用独立证据/快照；参数填精确formula/segmentation/label/exit版本，不只填V0.2。附表不提供自动计算或语义校验。

| 表 | 主键与用途 | 专项约束 |
|---|---|---|
| bar_observations.csv | observation_id，单根事实/假设摘要 | source/evidence/snapshot关联，range/body分开，相对量参照独立登记，不存在买卖量符号推断 |
| wave_observations.csv | wave_record_id，wave_id的截至当时版本 | 起止与确认时间分开，confirmed/provisional不混用；量窗口及端点归属冻结，修订追加supersedes_id |
| responses.csv | response_record_id，独立测试响应记录 | test/evidence关联，最大依赖时间合法；response_status依15，旧状态保留，as_of与成熟标签分开 |
| management_reviews.csv | management_record_id，计划/库存/风险复核 | 计划版本与exit_rule_version不改旧定义，请求、成交/库存从原orders/risk关联，净R无实际成交为unknown |

record_mode包含manual_observation_snapshot，但该模式仅描述当前快照，不晋级prospective_shadow。训练run_id/training_replay/已见样本写独立冻结训练卡，通过decision_record_id链接；不改基础CSV历史字段。evidence_ids/dependency_ids为分号分隔，不把多个引用当独立票数。structure_revision_id与decision_record_id必须解析到当时版本；空candidate_id的描述卡不能进入候选收益分母。
