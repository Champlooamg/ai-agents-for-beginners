# 视角一：方法结构视角（概念·逻辑·体系）

*本视角回答"这套方法的骨架是什么、为什么自洽"。*

## 1. 市场运行的底层模型（第 1-5 章）

### 1.1 波浪（Ch1）
- 价格以**分形波浪**运动：小波浪组成中波浪，中波浪组成大波浪。
- 分析**上涨波与下跌波的关系**（持续时间、速度、幅度）→ 判断趋势性质。
- 波浪分析本质是展示**供需相对变化**。
- **应用场景**：任何图表的初级阅读；判断一波行情是"健康推进"还是"勉强延伸"。

### 1.2 价格循环（Ch2）
- 市场只有两种运动：**趋势**（多/空）+ **交易区间**（吸筹区/派发区）。
- 四阶段循环：吸筹 → 上升趋势 → 派发 → 下降趋势，在所有时间框架中同时发生。
- **最小阻力路径**：专业人士验证"没有卖家"之前不发起上涨；卖盘压倒性存在时最小阻力向下。
- 三个位置：吸筹/上升趋势 = 买入位置；派发/下降趋势 = 卖出位置；无操作 = 中性位置。
- **核心价值**：判断市场处于循环哪个阶段 → 即便不会利用趋势，也能靠"不逆势"避免亏损。

### 1.3 趋势（Ch3）
- 趋势 = 价格移动的**最小阻力线**。推动浪 + 调整浪构成趋势。
- 三种方向（多/空/横向）× 三种持续时间（长/中/短，按嵌套关系定义而非硬性时间规则）。
- **关键论证**：短期交易成功需要"完美的时机"，初学者应从长期交易开始。
- **情绪驱动**：多头市场由贪婪驱动（直到超买），空头市场由恐惧驱动（直到超卖）。

### 1.4 趋势评估（Ch4）——强弱分析的四个工具
核心原则：**不比绝对值，只做比较**（当前运动 vs 先前运动）。追随强势、对抗弱势。

| 工具 | 测量对象 | 强势信号 | 弱势信号 |
|---|---|---|---|
| **速度** | 价格移动角度 | 比过去移动更快 | 比过去移动更慢 |
| **投射** | 推动浪行进距离 | 每个推动浪超越前一个 | 推动浪无法取得新进展 |
| **深度** | 调整浪行进距离 | 回撤变浅 | 回撤加深 |
| **趋势线/通道** | 定义范围与角度 | 多次触及被尊重 | 斜率太大易被突破 |

- **水平线**：≥2 个低点 = 支撑；≥2 个高点 = 阻力；同线双角色 = **轴线**（被突破的阻力变支撑，反之亦然）。
- **通道**：需求线/供应线平行锚定 → 超买线/超卖线；价格超出通道端 = 超买/超卖状态，暗示趋势减弱。
- **反向线**：无明确趋势时，先建供应线再派生需求线（升势中）或反之（跌势中）。
- **收敛线**：独立于趋势线连接高/低点；**无法触及原超买线 = 弱势信号**（升势中），反之亦然。
- **关键论证**：突破趋势线本身不是结论性信号——可能是真突破或假突破，重要的是突破方式、条件与之前的行为。

### 1.5 交易区间（Ch5）
- 市场**大部分时间**处于区间状态 → 区间极其重要。
- 区间 = 先前运动被阻止、供需相对平衡之地；区间内发展吸筹或派发，构建后续运动的"因"。
- 区间提供**最有利的风险/回报**；大操作 = 在区间内正确建仓吃趋势运动。
- 区间三种意图：吸筹（向上准备）/ 派发（向下准备）/ 随机波动（无专业兴趣，应忽略）。
- **因果律的应用**：区间时间越长 → 后续运动越大；短区间产生短运动。
- 定义区间只需两个点构成通道；关键在端点——端点突破提供极佳交易机会。

## 2. 方法论结构（第 6 章）——4 种基本方案

### 2.1 基本吸筹结构 #1（五阶段事件链）
- **溪线（Creek）**：吸筹结构的阻力水平（由 AR 高点 + B 阶段高点确立）。
- **CHoCH**（性质改变）：两次出现——A 阶段（趋势→盘整）、C 阶段低点到 SOS 高点（盘整→升势）。
- A 阶段事件：**PS**（初步支撑，必失败的第一次止跌尝试）→ **SC**（抛售高潮）→ **AR**（自动反弹，定区间上限）→ **ST**（二次测试，结束 A 阶段）。
- B 阶段事件：**UA**（上冲行动，测 AR 高点）+ **ST as SOW**（测 SC 低点）。
- C 阶段事件：**Spring**（弹簧/震仓，三种类型：测试型 / LPS 型 / TSO 终端震仓）。
- D 阶段事件：**SOS**（强势初现 = JAC 跳过溪线）+ **LPS**（最后支撑点）+ **BU**（回拉 = BUEC）。
- E 阶段：区间外多头趋势，SOS+LPS 连续产生升高的高低点。

### 2.2 基本吸筹结构 #2（C 阶段测试未达低点）
- 发生条件：背景强势——大资金积极买入，不让其他人低位接货。
- **识别更难**（失去 Spring 这个信心点）；区间突破的第一个 SOS 通常丢失。
- **唯一可行买入机会在 BUEC**（回到溪线边缘）。

### 2.3 基本派发结构 #1（镜像推理）
- **冰线（ICE）**：派发结构支撑水平（AR 低点 + B 阶段低点）。
- A 阶段：**PSY**（初步供应）→ **BC**（抢购高潮）→ **AR**（自动反应）→ **ST**。
- B 阶段：**UT**（上冲，测 BC 高点）+ **mSOW**（次要弱势信号）。
- C 阶段：**UTAD**（派发后上冲）。
- D 阶段：**MSOW**（主要弱势信号，破冰线 + CHoCH）+ **LPSY**（最后供应点）。
- E 阶段：区间外空头趋势。

### 2.4 基本派发结构 #2（镜像同上，唯一做空机会在突破测试 LPSY）

**结构视角的方法论要义**：市场是活的有机体，两个完全相同的结构不存在 → 方法必须"固定要素（事件+阶段）+ 灵活呈现"。

## 3. 三大基本定律（第 7-9 章）——方法的理论地基

### 3.1 供需定律（Ch7）
- 基本陈述：需求 > 供应 → 涨；供应 > 需求 → 跌；平衡 → 维持。
- **常见误区澄清（关键论证）**：
  - 错误①：价格上涨是因为买家多于卖家——错。买卖家数量永远相等（有买必有卖）。
  - 错误②：把一切买入叫需求、卖出叫供应——错。应按**订单类型**区分：
    - **被动限价单**（BID 列买单=需求 / ASK 列卖单=供应）：只代表意图，**能阻止运动但不能推动运动**。
    - **主动市价单**：唯一有能力推动价格的订单（含止损单转市价）。
- 价格上涨途径：买家主动买入 或 空头止损被触发。下跌同理镜像。
- **缺乏兴趣**：供应缺失可促涨（ASK 挂单减少），需求缺失可促跌——小力量即可推动价格。
- 结论：无论订单来源（散户/机构/算法），结果都是流动性添加；理解供需互动靠**价格+成交量**两个工具。

### 3.2 因果定律（Ch8）
- 事情不凭空发生：要看到价格变化（效应），必须先构建根本原因（因）。
- 因 = 横向期间信息灵通/不灵通交易者之间的**重大易手**；效应与因**严格成正比**。
- **点数图（Point & Figure）量化因果**：
  - 横向计数估计目标：吸筹产生向上计数、派发向下投射。
  - 计数测量：吸筹 = LPS 到 PS/SC 的列数；派发 = LPSY 到 PSY/BC；再吸筹 = LPS 到 AR；再派发同理。
  - 格子数 × 格子值，加到 LPS/LPSY 价格（经典投射）或加到极端点价格（温和投射）；分阶段计数获得更保守投射。
- **作者的态度（关键论证）**：点数图制备主观性太强（多种画法）→ "使我对这个工具失去信心"；更推荐斐波那契/艾略特/谐波做区间垂直投射。
- 例外情形：高潮事件可以在没有大量准备的情况下引起急剧转向（V 形反转）；并非所有区间都有"因"。

### 3.3 努力与结果定律（Ch9）
- 努力 = 成交量；结果 = 价格。价格行为必须反映成交量行为；没有努力就不可能有结果。
- **和谐** = 运动强势（延续）；**发散** = 运动弱势（反转预备）。
- **成交量第一关键概念**：大交易者的参与通过成交量增加识别。
- 五层分析表（由简到繁）：

| 分析层 | 和谐（强） | 发散（弱） |
|---|---|---|
| 单根蜡烛 | 量峰=宽区间；低量=窄区间 | 量峰=窄区间 |
| 随后位移 | 量增产生同向延续 | 量增后反向位移 |
| 完整运动 | 推动=量增、回撤=量减 | 推动量减 / 回撤量增 |
| 按波浪（Weis） | 推动波浪量 > 回撤波浪量 | 上升波浪渐小 / 下跌波浪更大力 |
| 到达关键水平 | 带量有效突破 | 带量假突破 |

- 适用水平类型：水平线、趋势线/通道/反向线/收敛线、动态水平（均线/VWAP/带）。
- 趋势中的努力/结果：大趋势后的强成交量 = 趋势将终（抛售高潮/派发开启）。
- **缺乏兴趣的反转**：底部/顶部之后的小成交量 = 缺乏卖压/买压 → 价格容易反转。

## 4. 吸筹与派发全过程（第 10-13 章）

### 4.1 吸筹（Ch10）
- 定义：空头运动后的横向运动，大资金吸收股票（弱势手 → 强势手转移）。
- **股票控制**：跌得越多，股票越多转入强势手；吸筹结构内完成最终吸收。
- **大资金为何分批买**：一次性挂大单会自己推高价格拿到更差均价 → 需要谨慎计划以最低均价吸收。
- **操作手法**：制造极度弱势环境（坏新闻配合）；核心事件 **Spring** 的三重功能：①触及多头止损 ②诱使不知情者卖出 ③从中获利。
- 驱赶短线获利者：制造平淡无聊的市场背景。
- **对手方与流动性（关键论证）**：止损触发与恐慌卖出都是市价卖出 → 恰是吸筹者需要的对手方；空头突破时建空者的止损回补则增加多头力量。
- **最小阻力路径验证**：发起上涨前反复测试（向下运动+成交量缺失 = 缺乏卖出兴趣）；区间内可出现多个震仓。
- 吸筹区间共同特征：
  1. 成交量与波动率随区间发展**下降**（可卖股票越来越少）；
  2. 对区间高区域的无量测试；
  3. 对先前低点的 Spring；
  4. **向上运动比向下运动更宽更流畅**（高质量需求涌入）；
  5. 区间末端出现升高的高点和低点（买家完全控制）。
- 多头运动开始：吸收完毕 + 需求轻微增加 = 价格突然向上。

### 4.2 再吸筹（Ch11）
- 与吸筹过程完全相同；唯一区别：吸筹起于停止空头运动，再吸筹起于**上升趋势的暂停**。
- 结构持续时间由强势手/弱势手持股比例决定：强势手占比高 → 时间短；弱势手占比高 → 时间长。
- **再吸筹 vs 派发的辨别**（威科夫交易者最困难的任务之一）：两者都以上升趋势停止开始——必须自动化吸筹区间特征。

### 4.3 派发（Ch12）
- 镜像过程：信息灵通的专业人士卖出股票给弱势手，制造极度强势环境（媒体配合、利好新闻）。
- 核心事件 **Upthrust（上冲）**三重功能：①触及空头止损 ②诱使不知情者买入 ③从中获利。
- 派发区间共同特征（与吸筹镜像）：
  1. 区间发展期间**高成交量高波动率**（宽价格波动、量相对高且恒定）；
  2. 对区间低区域的无量测试；
  3. 对先前高点的向上震仓；
  4. **向下运动比向上运动更宽更流畅**；
  5. 区间末端降低的高点和低点。
- 空头运动开始：需求耗尽 + 供应轻微增加 = 价格急剧向下。

### 4.4 再派发（Ch13）
- 空头趋势中的暂停刷新；大空头市场可有多个再派发。
- 专业人士区间顶部卖出 + 底部部分回补（提供支撑防过早推低）；区间内增加空头头寸。
- 同样面临"再派发 vs 吸筹"的辨别难题。

## 5. 事件体系（第 14-20 章）——7 类事件全解

**总纲**：吸筹与派发事件相同，只是名称改变；建议从**功能角度**观察，减去刚性。

### 事件#1 初步停止（Ch14：PS/PSY）
- 第一次止住趋势的尝试，**结果总是失败**；趋势即将结束的早期警告。
- 图表表现（常被误解，三种皆可）：①量增范围扩大的单根 K 线；②一组窄范围+恒定高量 K 线；③单根高量大影线 K 线。
- Tom Williams《掌握市场》引述：长时间运动后伴随显著量增的大趋势 K 线，通常表示**相反的情绪**——长跌后放量收低的大阴线 = 专业买入的明确指示。
- **心理学（三类流动性提供者）**：贪婪者（怕错过追入）、恐惧者（亏损套牢割肉）、聪明者（预见转向但时机不精被止损打出）。
- 用途：①停止顺原趋势交易；②极好的获利了结点。
- 重复的 PS/PSY 预示**耗尽型终点**（最后低点无成交量峰值）。

### 事件#2 高潮（Ch15：SC/BC）
- 先前趋势的顶点运动；专业人士在极端条件出现的信号。
- **关键论证——高潮不必是结构最大终点**：B 阶段多个测试与 C 阶段 Spring/UTAD 通常会震出更极端的终点。
- **确认依赖**：高潮必须被 AR + ST 确认；未见 AR/ST 之前只是"潜在高潮"。
- 图表表现三种形态同 PS（单根宽幅放量 / 一组窄幅恒量 / 单根大影线）。
- **耗尽型高潮（作者原创观点）**：
  - 下降趋势不一定以高潮量结束——控制性卖出逐渐消失也可止跌（耗尽型抛售高潮）。
  - 信号：持续越来越高的 PS + 整体成交量减少 = 卖出被吸收。
  - 作者提议向威科夫社区新增事件标签："抛售耗尽/抢购耗尽"。
- 用途：①停止顺原趋势交易；②最后明确获利了结机会；不建议在此开新仓（风险太高）；资深者可做剥头皮向 AR 反弹。

### 事件#3 反应（Ch16：AR）
- 第一个暗示市场情绪改变的伟大信号：从单方控制 → 平衡市场；确认高潮。
- **距离的含义（比较原则）**：常态 50 点波动的市场出现 100 点 AR = 更强的底部。
- 短距离+无量 AR = 市场尚未平衡 → ST 可能较快出现并超出结构界限 → 怀疑其实是再派发（假吸筹）。
- 解剖：运动开始量大（高潮量）→ 渐减 → 枯竭即结束；范围同步由宽变窄。无机械规则，纯判断力。
- 三大用途：①定义结构界限（AR 定上限/下限）②回溯识别真高潮 ③提供背景（高潮后必有测试预期）。
- **操作机会**：在 AR 结束处平仓剥头皮利润；可降时间框架在 AR 末端寻找反向的小型结构（次要吸筹/派发）。
- 发生机制：SC 后 = 供应耗尽 + 空头回补 + 新需求出现；BC 后镜像（需求耗尽 + 多头回补 + 新供应出现）。

### 事件#4 测试（Ch17：ST 与通用测试）
- **二次测试（ST）**：A 阶段第四事件；功能 = 确认主动卖方的放弃，市场进入平衡谈判环境。
- 成功标准（按重要性排序）：**①成交量减少 ②范围变窄**；不必保持在 SC 低点上方（市场非刚性）。
- ST 位置的中性解读：区间上半部 = 买家失衡线索；略低于 SC = 卖家失衡线索。
- **B 阶段测试的双标签体系**（重要概念——概念 vs 事件分离）：
  - 上端测试（暂时破阻力回归）：吸筹标 UA / 派发标 UT；停留一段时间可标 mSOS。
  - 下端测试（产生更低低点）：吸筹标 ST as SOW / 派发标 mSOW。
  - 实时中不知方向 → 简化标 "ST in B" 完全有效。
- **通用测试（VSA 概念）**：进入先前高量区域时——量低 = 有效测试（缺乏兴趣，趋势就绪）；量高相对 = 无效测试（还有交易者愿意推动）。
- 三大测试位置：
  1. **震仓后测试**（C 阶段）：最佳风险/收益比——止损近（结构端点），目标路径宽。
  2. **突破后测试**（D 阶段）：验证溪线突破有效性；止损可放结构中段。
  3. **趋势测试**（E 阶段）：快速趋势暂时停顿发展新结构时的加入机会。
- 图表表现（VSA 术语）：强势背景找**无供应**（窄幅空头蜡烛）；弱势背景找**无需求**（窄幅多头蜡烛）；量低于前两根 K 线即有效。
- **ST vs 通用测试的区别**：概念相同；ST 是威科夫特定事件（结构层面内涵），通用测试是 VSA 全局事件（只关注行动本身）。

### 事件#5 震仓（Ch18：Spring/UTAD）——全书最重要事件
- **"没有其他事件能为分析增加更大的力量。"**
- 前提条件两个：先前趋势已停止 + 显著因已构建（B 阶段发展）。
- **零和游戏论证**：每笔卖出必配买入；弱势手的所有订单被强势手吸收——震仓是流动性的收割场。
- **为什么震仓必然存在（关键论证）**：任何显著趋势运动之前都发展过震仓——市场通过寻找流动性移动；大资金需要"真突破的假象"吸引对手方。那个订单交叉是他们需要四处走动的"汽油"。
- 图表三种表现：
  1. **单根 K 线**（锤子线）：穿透后同根内收回，长影线 = 拒绝。
  2. **2+ 根 K 线形态**：花费时间越长 = 震仓力量越小（反转越快力量越大）。
  3. **次要结构**：控制不明确 → 在潜在 Spring 位置发展小型吸筹结构（趋势内的结构套结构）。
- **四重功能**：逐出突破交易者（含突破策略机器人——机器人再激活动量策略产生更多压力，故震仓常伴量峰）；逐出恐惧者；踢出聪明者；专业人士完成操作。
- 判断"潜在震仓 vs 有效突破"的两条线索：
  1. B 阶段 ST 类型：UA（买家力量）→ 倾向低点出 Spring；mSOW（卖家力量）→ 倾向高点出上冲。
  2. 突破后价格行为：未能保持在区间外并重新进入 = 强烈反转进入信号（假突破概率增大）。
- **标签纪律（作者反复强调）**：Spring 必须引起区间**向上突破**，否则只是测试；UTAD 必须引起**向下突破**。其他位置的震仓按位置命名（普通震仓/普通上冲）。
- **Spring 三类型**（按突破时供应强度）：
  | 类型 | 供应状态 | 特征 | 操作含义 |
  |---|---|---|---|
  | Spring #1（终端震仓，TSO） | 供应强烈 | 量突增+大穿透大范围 | 需强需求回流确认 |
  | Spring #2 | 浮动供应中等 | 量/范围增加+中等穿透 | 需连续测试吸收 |
  | Spring #3 | 供应耗尽 | 轻微到达+量减+范围窄 | **最强，可直接买入** |
- 变体：区间**内**的 Spring（表示更强背景强势）；普通震仓（上升趋势中无广泛准备的空头推动）；Spring 测试（须量减、范围窄、保持在 Spring 水平上方）。
- UTAD 家族：UTAD（C 阶段测试，量中等或强烈）、次要 UTAD（局部高点的震仓）、UTAD 测试（应显示更少热情：低点下方停止+量减）、终端上冲（穿透异常大、快速回到区间内）、普通上冲（下降趋势中几乎无准备——很好的做空机会）。
- **术语溯源**：Spring 是 "Springboard（跳板）" 缩写，由 Robert G. Evans（威科夫学生）改进自威科夫原始概念"终端震仓"。

### 事件#6 突破（Ch19：SOS/SOW）
- C 阶段测试后沿最小阻力方向的运动；专业人士承担的**最大承诺证明**。
- **关键论证：突破本身不是交易机会**——它只是提醒；机会在随后的确认测试中（大量交叉订单的微妙区域，控制权可能改变）。
- 第二次 CHoCH：市场从横向化 → 新趋势阶段；ChoCh = 强烈运动 + 轻微回撤的组合体。
- **无量突破的解读**：浮动供应极少（没交易者愿意卖）+ 中等买家攻击性 = 也可突破——不必量峰。
- 真突破的三条最有力的指示（按可靠性排序）：
  1. **不立即重新进入交易区间**（最可靠——表示低位无兴趣，运动被大资金支持）；
  2. 缺乏兴趣的表示（测试蜡烛窄幅、交织、量小于突破运动）；
  3. 突破距离明显（无预定义数值，但应显著）。
- **SOS（强势信号/JAC）**：源于 C 阶段低点、突破溪线的向上运动；确认时回撤为 BUEC，若失败回区间则为 UT。
  - 验证：运动轻松、到达区间中点、回撤保持 Spring 低点上方。
  - **SOS Bar**：宽幅、收高点、量增的多头 K 线（或多头缺口）= 机构买入点，可作入场触发器。
- **SOW（弱势信号/MSOW）**：镜像；源于 C 阶段高点、突破冰线；可能是第 2/3/4 次尝试中最成功的一次。
  - **SOW Bar**：宽幅、收低点、量增的空头 K 线（或空头缺口）= 专业卖出点。

### 事件#7 确认（Ch20：LPS/LPSY/BUEC/FTI）
- 突破只是"潜在的"；确认来自它的测试——成功测试 = 确认事件。
- **威科夫首选入场位**：左边所有价格行动已可见（吸筹/派发的努力可观察）→ 风险相对低的机会。
- 确认合格标准：突破行进显著距离 + 测试窄幅交织低量 + 价格不重新进入区间。
- **警告信号**：确认测试上相对高的量 = 该方向有潜在兴趣 → 等待连续测试；宽幅高量的修正运动 = 潜在突破终将变成震仓。
- **入场执行**：买 = 等 SOS Bar → 市价单 / 突破止损单 / 限价买单；止损移到 LPS 与被突破溪线下方。卖 = 镜像。
- **量化入场触发器（前瞻性观点）**：自由裁量方法的主观性是最大劣势，人类情绪是交易策略最薄弱环节 → 建议量化触发器（如"空头蜡烛后多头蜡烛"的简单反转 + 均线/点数/VWAP/Delta 等变量），并做严格回测（数据质量、佣金、滑点）。
- **LPS 三类**（按之前的运动）：震仓后的 LPS（= Spring 的测试）、区间内 LPS（SOS 后的空头反转）、区间外 LPS（突破后测试 + 趋势中的回撤）。
- LPSY 镜像三类；量低 = 买家缺乏兴趣（好做空位）；但高量需小心 = 可能是增加卖出兴趣的信号。

## 6. 阶段体系（第 21-25 章）——A-E 五阶段

| 阶段 | 功能 | 组成事件 | 关键判断 |
|---|---|---|---|
| **A** | 停止先前趋势 | PS/PSY、SC/BC、AR、ST | 趋势背景→区间背景 |
| **B** | 构建因 | UA/UT、ST as SOW/mSOW 连续测试 | **比例上应大于 A 和 C**；失衡时 B 可能很短 |
| **C** | 测试 | Spring/UTAD | 检查投入程度；高参与=尚未吸收完毕 |
| **D** | 区间内趋势 | SOS/SOW + LPS/LPSY（+BU） | 突破+确认；警惕第三情景（突破失败出反向 Spring） |
| **E** | 区间外趋势 | SOS/SOW + LPS/LPSY 连续 | 实施全部趋势评估工具 |

- **背景的优势论证（Ch24）**：传统技术分析者见阻力就做空；已正确识别阶段的威科夫交易者可能已建立"价格将有效突破该阻力"的更大概率，甚至考虑买入。
- **机构也会输（Ch24 关键论证）**：并非所有机构都赚钱——大量机构与散户一样是输家；这些亏损机构是大资金最喜欢的受害者（资本量大）。
- B 阶段比例性不满足（B 比 A/C 短）= 吸筹者紧迫 = 为趋势增加更大力量。

## 7. 交易体系（第 26-27 章）

### 7.1 三元素决策框架（按重要性顺序）
1. **背景**：图表左边的东西（当前时间框架 + 更高时间框架）；**交易有利于更大的结构**——始终优先更长期结构的发展方向。识别背景 → 直接丢弃反向交易（"我们无法获胜，但至少我们不会亏损"）。
2. **结构**：方法论基石；理解结构内谁获得买卖控制权。五步纲领：停止先前趋势 → 构建因 → 评估竞争 → 开始趋势运动 → 确认方向性。
3. **交易区域**：拍卖理论——大资金需要对手方；震仓处开仓，流动性区域平仓。**交易区域是价格磁铁**：产生足够兴趣吸引待执行订单，流动性使价格倾向来到这些区域。可间接利用：Spring 处大量买入的大资金必须至少持有到下一个主要流动性区域。

### 7.2 主要头寸（Ch26）——三大入场区与信任/收益权衡
核心权衡：**结构发展越大 → 信心越大但潜在收益越低；越早获得信号 → 潜在行程越大但可靠性越低。**

| 阶段 | 入场类型 | 风险:收益 | 可靠性 | 备注 |
|---|---|---|---|---|
| C | 震仓 | 最佳 | 较低 | 仅低成交量震仓推荐；放警报监控端点即可 |
| C | 震仓测试 | 优秀 | 中等 | **威科夫交易者最爱**；须不创造新极端 |
| C | 最后支撑点 | 优秀 | 低 | 难以实时识别（多在结构#2） |
| D | 区间内趋势 | 良好 | 较高 | 用 SOS/SOW bar、次要结构或次要震仓 |
| D | 突破测试(BUEC/FTI) | 中等 | 高 | **Wyckoff 原始首选位置** |
| E | 区间外趋势 | 较低 | 最高 | 最"安全"；潜在路径较小 |

- D 阶段三种入场方式：重要 K 线（SOS/SOW bar）、降低时间框架找次要结构、次要震仓（标 LPS/LPSY）。
- E 阶段：趋势极快时等普通震仓/普通上冲加入；技术目标已覆盖则推迟入场。

### 7.3 决策制定（Ch27）——执行层工具箱
- **重要 K 线（Significant Bar）四特征**：①范围比先前 K 线更宽 ②成交量相对更高 ③收在运动方向半区（多头收上半、空头收下半）④承诺（多头收过前阻力、空头收破前支撑）。若无单根清晰 K 线，可合并两根正常 K 线构造。
- **运动反转概念**：标记控制市场的最后一根重要 K 线；**反向重要 K 线突破其范围末端** = 控制权反转确认（空头收破上升重要 K 线低点 = 升势结束信号；镜像同理）。
- **仓位管理**：强烈建议同时发送全部 3 个订单（入场/止损/止盈）——防止情绪化移损与电子故障裸仓。
- **头寸规模**：基于账户的固定风险（每笔 ≤ 1%）；入场-止损距离决定风险百分比，止盈距离决定 R:R。示例：$5000 账户 1% = $50 风险；1:3 R:R → 赚 $150 或亏 $50。避免负 R:R 交易。
- **入场订单三式**：市价单（积极）/ 止损单（顺势被动）/ 限价单（逆势被动）。
- **止损放置规则表**：

| 入场类型 | 止损位置 |
|---|---|
| Spring 直接入场 | Spring 低点下方 |
| 上冲直接入场 | 上冲高点上方 |
| Spring 测试入场 | SOS Bar 下方 或 Spring 低点下方 |
| 上冲测试入场 | SOW Bar 上方 或 上冲高点上方 |
| 次要结构入场 | 整个结构端点外 |
| 突破测试(BUEC)入场 | SOS Bar 下方 + 被突破溪线下方 |
| 突破测试(FTI)入场 | SOW Bar 上方 + 被突破冰线上方 |

- **移动止损**：作者个人不用（挤压价格空间、易被触及）；建议回测验证。
- **止盈五式**：①高潮 K 线证据（市场极端+无左侧参考时的好方法；高潮量 = 放弃头寸的充分理由）②A 阶段四事件完成（先前趋势结束的充分理由）③流动性区域（结构端点：SC 低点/AR 高点等+先前高低点，优先高时间框架）④**成交量分布水平**（VPOC/VAH/VAL/VWAP——衔接第二本书）⑤裸 VPOC（未回测的旧 VPOC）。
- 三式联用示例：LPSY 做空 + SOW Bar 范围上沿达 VPOC/VWAP（拒绝续涨）→ 入场；止损 = SOW Bar 上方 + 冰线上方 + 被拒绝的量价水平上方。

## 9. 实战流程图（把全书记忆压缩成一张执行清单）

```
第 1 步 定背景（先看大时间框架）
  ├─ 高时间框架在吸筹后多头阶段？ → 只找买入，丢弃做空
  ├─ 派发后空头阶段？ → 只找卖出，丢弃做多
  └─ 分不清？ → 等待，不出手

第 2 步 读结构（当前时间框架标注事件与阶段）
  ├─ 有 PS/PSY + SC/BC + AR + ST？ → A 阶段完成，进入观察
  ├─ B 阶段量减 + 测试渐浅？ → 吸筹倾向；量高宽幅 → 派发倾向
  ├─ C 阶段震仓出现？ → 等测试确认
  └─ 突破 + 确认测试成功？ → E 阶段，只做顺势

第 3 步 选入场（按风险偏好选位置）
  ├─ 激进：C 阶段低量 Spring 直接入场（止损：Spring 低点下方）
  ├─ 稳健：震仓测试入场（威科夫最爱；量减+范围窄+不创新极端）
  ├─ 保守：突破测试 BUEC/FTI 入场（Wyckoff 首选）
  └─ 顺势：E 阶段 SOS/SOW Bar 或普通震仓加入

第 4 步 管头寸
  ├─ 同时下 3 单（入场/止损/止盈），≤1% 账户风险
  ├─ 止损：查上面的止损放置规则表
  └─ 止盈：流动性区域（前高低点/结构端点/VPOC/裸 VPOC/高时间框架水平）
```

## 10. 高频实战场景速查

### 场景 A：看到长跌后放量巨阴线
→ 不是做空信号！按 Tom Williams 引述，这是**专业买入**的明确指示（初步停止/抛售高潮候选）。行动：停止做空、获利了结、开始标注 A 阶段四事件。

### 场景 B：区间内突然破位下杀又快速收回
→ 潜在 Spring。三查：①B 阶段有无 UA（有 → 倾向 Spring）②收回速度（越快越强）③量（Spring #3 量减 = 最强可直接买）。确认后等测试入场，止损 Spring 低点下方。

### 场景 C：突破区间后想追
→ **不追**。突破本身不是交易机会（大量交叉订单区）。等确认测试：窄幅+交织+低量+不重入区间 → 入场；宽幅高量回撤 = 潜在震仓警告，取消计划。

### 场景 D：吸筹区间还是派发区间分不清
→ 最困难任务。用五条特征对照表（量趋势/测试反应/K 线宽窄/高低点序列/震仓位置）；实在分不清 = 减小仓位或不交易（书中逻辑：只做看得懂的背景）。

### 场景 E：趋势已经走了一段还想上车
→ E 阶段操作最安全但路径最小。等普通震仓/普通上冲（趋势中无准备的推动）；技术目标已覆盖 → 推迟入场，等震仓+区间外测试放止损。

### 场景 F：持有多单，何时走？
→ 五式止盈：高潮 K 线（极端位置+量峰）、A 阶段四事件完成、流动性区域、VPOC/VWAP 拒绝、裸 VPOC。市场产生更近的新流动性区域 → 目标随之更新。

## 11. 风控红线（书内论证直接映射）

1. **逆背景 = 首要亏损来源**：不逆势不靠纪律靠方法——先定背景再谈入场。
2. **情绪管理 = 订单管理**：三单同发，杜绝"到时候再说"（作者：大多数结局是高于预期的亏损）。
3. **单笔风险 ≤ 1%**：1:3 R:R 下 33% 胜率即打平；负 R:R 交易原则上不做。
4. **主观性是自由裁量方法的死穴**：量化入场触发器 + 回测（数据质量/佣金/滑点），把"人类情绪"这个最薄弱环节替换成统计优势。
5. **标签服务于逻辑，不反过来**：实时中不知道方向 → "ST in B" 式中性标签完全有效；功能优先于礼仪。

# 视角三：复习整合视角（记什么·怎么串·和第二本怎么接）

## 12. 一页复习卡（30 秒版）

- **三定律**：供需（谁主动谁推动）｜因果（时间 × 力度 = 后续运动）｜努力结果（量价和谐=延续，发散=反转预备）。
- **两过程**：吸筹（弱手→强手）与派发（强手→弱手），在横向区间完成。
- **七事件**：初步停止 → 高潮 → 反应 → 测试 → 震仓 → 突破 → 确认。
- **五阶段**：A 停止先前趋势｜B 构建因｜C 测试｜D 区间内趋势｜E 区间外趋势。
- **四结构**：吸筹#1/#2、派发#1/#2（#2 = C 阶段测试未达端点，唯一入场在 BUEC/LPSY 突破测试）。
- **三入场**：C 震仓测试（最爱）｜D 突破测试（Wyckoff 首选）｜E 顺势（最稳最小）。
- **两根关键 K 线**：SOS Bar（宽幅收高量增 = 机构买点）｜SOW Bar（宽幅收低量增 = 机构卖点）。
- **一铁律**：背景 > 结构 > 交易区域；先大后小，永不逆大背景。

## 14. 易混淆概念对照表

| 概念对 | 区别要点 |
|---|---|
| PS vs SC | PS = 必失败的第一次止跌尝试；SC = 真正止住的高潮；重复 PS → 耗尽型终点 |
| ST vs 通用测试 | ST = 威科夫结构事件（有阶段内涵）；通用测试 = VSA 全局行动 |
| Spring vs TSO | Spring = 轻/中量的短运动；TSO = 深穿透+高量的急剧运动 |
| Spring vs 普通震仓 | 位置不同：Spring 在吸筹区间，普通震仓在上升趋势（再吸筹）中 |
| UA vs UT | 同一行动双标签：吸筹区间标 UA，派发区间标 UT |
| ST as SOW vs mSOW | 同上双标签：吸筹标 ST as SOW，派发标 mSOW |
| SOS vs JAC | SOS 突破溪线后即称 JAC（跳过溪线）；本质同一运动 |
| LPS vs BUEC | LPS = 区间内升高的谷底；BUEC = 突破溪线后回踩溪线边缘的特定 LPS |
| 突破 vs 震仓 | 靠"是否重入区间"+ 后续测试区分；实时中等确认 |
| 再吸筹 vs 派发 | 都起于上升趋势停止——威科夫最难辨别题，靠特征表自动化 |

## 15. 三条"作者私货"（超出经典威科夫的增量）

1. **耗尽型高潮**（抛售耗尽/抢购耗尽）：作者向社区提议的新事件——无量峰的趋势终点；信号 = 持续越来越高的 PS/PSY + 整体量减。
