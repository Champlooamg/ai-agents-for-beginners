# 中国市场威科夫投研体系 · 研究版 V0.2

版本：wyckoff-cn-0.2。建立/升级日期：2026-10-08，Asia/Shanghai。

**当前采用纯威科夫理论。研究规范和人工记录工具已建立，真实Shadow未启动，策略有效性未验证，无新增交易权限。**

本轮基于五份读书笔记补齐逐根/逐波协议、测试响应与命名分歧、初始吸筹/再吸筹清单、持仓退出及行动序列训练。仅使用二手笔记，原著及经验效果未独立核验。[学习裁决](14_五书学习与来源裁决.md)记录25项取舍，[V0.2建设验收](建设验收_V0.2.md)说明边界。已有宏柏新材人工快照不等于预登记前瞻Shadow，旧研究卡保留原版本。

威科夫负责市场背景、品种比较、结构与供需假设、测试响应和潜在空间；独立数据核验、风险预算与现实成交决定是否具备行动条件。防过拟合、防未来函数、防模型幻觉贯穿全部流程。

## 首版范围与理论边界

中国市场首版按普通A股现货长仓研究：沪深主板、具备权限、历史充分且流动性可核验的证券，以完整日线组织结构。实际股票池和具体阈值尚待冻结。创业板、科创板、北交所、特殊状态、港股与其它品种各自需要制度与样本验证，不能宣称本版已经覆盖所有中国证券。

技术理论仅使用威科夫三大定律、五步法、量价与波段比较、结构/事件/阶段、相对强弱、九项检验和点数图研究。风险事实、公告、证券制度、成交模型和统计验证是必要配套；不另建其它技术战法或指标投票。

## 怎样开始

先看08中的数据缺口，依11逐数据源验收并取得合格快照；在查看结果前完成实验预登记。历史回放或绩效计算先通过12的运行闸口。用研究卡依次写市场、品种比较、空间限制、结构准备、时机与管理；每项事实引用evidence_id，再把候选变化追加到Shadow台账。风险否决、结构失效、超时、未成交和未知均保留。

参数未填齐时可以进行明确标识的描述记录与历史前缀练习，不能出完整策略效果。所有真实前瞻记录从实际采集时开始，不补签旧资料；自动识别、PIT加载、订单模拟与统计程序仍待实现。

学习练习先用17的行动序列与15的观察卡，冻结每步判断后再揭示下一步；日常研究按07把九检背景、响应窗口及退出计划填齐。16只登记数据/研究条件，不加入当前筛选。下一阶段按数据验收 → 基线冻结 → 标注复现 → 前瞻记录与独立验证推进。

本次完成治理规范和五项本地流程技能安装；QVeris MCP已配置为API目录发现工具，并完成免费发现与schema检查，但没有调用行情端点。没有任何具体供应商或快照通过验收，也未启动本地数据服务、运行回测或引入外部策略。当前下一项必要工作仍是：**按11完成数据合同验收，同时冻结最小威科夫基线及两个多头观察场景**。弱势场景首版用于风险观察与否决，不产生无权限做空收益。
