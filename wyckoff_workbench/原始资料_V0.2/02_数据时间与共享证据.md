# 数据、可得时间与共享证据

本文件是研究口径，不修改生产口径字典。所有时间使用带时区的ISO 8601，例如 `2026-10-08T16:20:00+08:00`。未知时刻填null，不凭日期补15:00。

## 时间链

| 字段 | 含义 |
|---|---|
| event_at | 行为发生时间；转折点所属K线时间 |
| source_available_at | 来源首次可得时间，须有依据 |
| ingested_at | 本研究系统实际接收时间 |
| available_at | 本次研究可使用时间；前瞻取不早于前两项的时刻 |
| last_dependency_at | 特征全部依赖数据的最晚available_at |
| confirmed_at | 当前状态或标签达到确认条件的时间 |
| decision_at | 研究卡冻结的判断时间 |
| earliest_order_at | 根据决策、交易日历和订单规则得到的最早模拟订单时间 |
| label_mature_at | 结果观察窗口及退出观察结束时间 |

必须 `last_dependency_at ≤ confirmed_at ≤ decision_at ≤ earliest_order_at`，且每项输入 `available_at ≤ decision_at`。同一时刻下还须验证因果顺序，不能用收盘后收到的完整日线模拟收盘前成交。

## 来源时点、缺失与修订记录

来源时间表示当时市场参与者最早能取得该信息的时间；本机接收时间表示研究系统实际拿到数据的时间。两者分开存，不能用今天的下载时间冒充历史可得时间，也不能仅凭数据中的交易日期推断盘中何时可见。每个 `source_available_at` 都要同时记录 `availability_basis`：来源原生发布时间、交易所/发行人公告时间、可复核的历史归档，或其它明确依据。依据不明时填 `unknown`，阻断依赖该时点的历史确认。

`evidence.csv` 的 `evidence_status` 只使用以下值：

| 状态 | 含义与处理 |
|---|---|
| `observed` | 已取得并校验的值；事实和单位可追溯 |
| `source_missing` | 应有记录但来源未提供；写明字段、期间和查询范围 |
| `source_unavailable` | 来源服务/接口当时或本次不可用；不能解释为无事件 |
| `confirmed_zero` | 来源明确给出零值且口径允许零；保留原始值与证据 |
| `not_applicable` | 该字段在此对象/期间确实不适用，并写明原因 |
| `unknown` | 现有材料无法判断以上哪种状态；阻断依赖它的结论 |

停牌、未上市、退市、无涨跌幅限制、行情缺根和合法零成交是各自的市场事实，不用 `source_missing` 或 `confirmed_zero` 互相替代。发现源数据更正时，保留旧证据，新增带新 `source_revision_id` 的记录，并用 `supersedes_id` 指向旧记录；已归档的决策不重写。

历史回放需要能说明数据在历史决策时点的版本。供应商今天返回的回补或修订历史K线，如果没有当时快照/版本证据，只能支持注明局限的描述性练习，不能单独通过点时数据验收。逐来源验收项目见[数据源验收清单](11_数据源验收清单.md)。

历史重建可使用有证据的当时公开可得时间，但实际下载发生于今天，必须保留两项时刻、availability_basis与record_mode=historical_reconstruction。只有实际接收并保存的前瞻记录能标 prospective_shadow。

转折确认延迟k根时，event_at为转折K线；confirmed_at为第k根依赖信息实际可得时。追加未来数据后，不改写已归档决策；修正新增revision_id、supersedes_id和原因。未完成周线和日线只作 provisional，不进入冻结日频触发。

## 原始与可比价格

原始价用于订单、涨跌停、报价单位与现金记账。结构比较用统一、仅基于当时已知公司行动的可比价。行情、复权因子、流通股本、行业分类、指数成分、证券状态各自保留版本和可得时间。

跨除权的支撑、阻力和锚点须按同一已知行动转换，并记录转换版本；不知道怎么转换时暂停该候选。不能用现在的前复权绝对价给过去设门槛。尺度不变是必要检查之一，不能单凭尺度不变宣称完整PIT合格。

## 共享基础特征

令A为已确认推动起点的可比低点，B为已确认推动终点的可比高点，P为回撤迄今低点，C为当前完整日线收盘。端点选择/确认方法先登记；B、P若仍临时，相关特征也标临时。

| 特征 | 公式/口径 | 异常处理 |
|---|---|---|
| 推动幅度 | `B/A-1` | A≤0未知 |
| 回撤比例 | `(B-P)/(B-A)`，只在B>A且P≤B时 | 不截断到0—1；超过1保留，非回撤状态另记 |
| 回撤相对峰值 | `P/B-1` | B≤0未知 |
| 收复比例 | `(C-P)/(B-P)`，只在B>P时 | 不截断；与“收复原峰”分别记录 |
| 当前净推进 | `C/A-1` | 与最高价触及的推进分开 |
| 推动/回撤用时 | 同一交易所日历上的完整交易日间隔；两个端点不同时重复计入 | 停牌日记日历间隔与实际有报价根数两项 |
| 收盘位置 | `(C-L)/(H-L)` | H=L未知，标价格限制/零振幅 |
| 相对成交量 | `V_t / mean(V_(t-w)…V_(t-1))` | w须预登记；排除当前日；基准≤0未知 |
| 相对强弱 | `log(C_t/C_(t-w))-log(I_t/I_(t-w))` | 固定基准、窗口、可比价格，缺任一端点未知 |
| 截至决策时已发生的保持 | 仅用decision_at之前已可得的收盘/低点相对被冻结边界 | 将窗口截到当时，保留as_of；不得引用后续成熟值 |
| 流动性 | 真实成交额、量、停牌/限制状态、报价缺失率 | 量×收盘仅单列粗估，不代替真实成交额 |

完整后续窗口的“推进后保持”是响应/结果标签，写入outcomes并带label_mature_at；不能回填成原决策特征。未来的某个新决策可以引用届时已经成熟的保持事实，但须建立新的as_of特征与依赖记录。

价格、量、成交额单位必须来自源说明；“手/股”“元/万元”“自然日/交易日”不能默认为同单位。公式计算由工具完成，手工输入注明复算方式。

## 同源去重

evidence_id对应一个事实；canonical_key由证券、时间区间、原始字段、变换版本及快照组成。结构、阶段与测试响应层都引用此ID，不各生成“独立确认”。feature_id另记录变换规则和全部dependency_ids。

例：回撤缩量分别支持LPS候选与供需测试解释，仍是一条事实。两个数据商镜像同一交易所行情属于校验来源，不构成两个独立交易预测信号。多个不同窗口/变换属于相关特征，统计增量仍需条件对照，不能靠去掉同名字段证明独立。

每条假设须列 supports、opposes、alternative_explanations、invalidate_if 与等待终止条件。missing_dependencies 单列，不进入支持计数。
