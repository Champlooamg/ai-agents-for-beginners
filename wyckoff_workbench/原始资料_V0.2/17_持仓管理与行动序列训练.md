# 持仓管理、执行纪律与行动序列训练 · V0.2

本章把书中的管理与训练建议纳入研究闭环。它提供人工研究协议；真实交易依已有权限与制度，当前体系production_permission=false。

## 入场前写完整管理计划

计划同时定义：原假设与保持条件、入场/失效/超时、初始风险参照、潜在空间依据、退出版本、复核频率、订单时点/数量/费用、部分成交/无法成交、老仓可卖与今日新仓、组合集中度和压力损失、加仓条件及总预算。价位漂亮不能抵消公告和组合风险。

计划止损距离不是最大损失保证，压力评估单列跳空、跌停、停牌与延迟。空间/风险比只描述几何关系，概率未知时不能算期望收益或Kelly仓位。目标未知阻断依赖目标的计划；有据的风险退出不因目标未知而停摆。

持仓复核不是不断寻找新的开仓理由。记录原假设是否仍受支持、已知反证与下一次预期响应；出现弱势扩大时不得解释成必然洗盘。加仓须有新增已观察证据、事前规则和剩余组合预算，不为回本摊平；本章不授权真实加仓。

## 退出版本与冲突优先级

独立风险约束/强制处置 → 原结构失效 → 冻结的时间与持仓退出规则。请求、合法可卖时点、实际成交与剩余暴露分开记录；已有可卖仓的风险请求不能因当日另有新仓而整体搁置。无法成交则继续报告剩余风险。

| 研究版本 | 正常退出的定义方向 | 必须冻结的内容 |
|---|---|---|
| EXIT-STRUCTURE | 支撑/结构被否定、强势未按约定保持 | 边界版本、响应/失效窗口、价格谓词、最早可执行时点 |
| EXIT-ZONE-BEHAVIOR | 到事前目标区后出现推进衰减、高潮或失败跟进 | 目标区来源、行为条件、观察窗口、卖出请求方式 |
| EXIT-TRAIL | 随已确认结构演进收紧风险参照 | 确认滞后、更新时点、只收紧条件与跨除权转换 |

这些是候选定义方向，均planned_incomplete。不同作者赞成/反对追踪止损的建议保留为替代版本，不混成随行情切换的最优规则。若组合退出，提前写OR/AND、优先级与同日顺序；不能等到目标、高潮和失效全部发生才执行强制风险退出。日OHLC顺序不明按预定保守口径或上下界，T+1按库存计算。

记录计划风险R、实际成交损益、费用、实现净R与压力损失。实际亏损可以超过1R；未成交的价格路径不能记为交易收益。任何风险变更带revision_id、理由和可得时间，亏损后不得临时放宽风险上限。

## 十项任务的A股日线改编

| 任务 | 本体系的可审计动作 |
|---|---|
| 准备状态 | 记录能否完成规定检查、疲劳/中断等自述；不建立未经验证的情绪分数交易阈值 |
| 预演 | 写好缺口、跌停、停牌、断流、T+1不能卖和部分成交的应对 |
| 形成构想 | 先收齐事实，再列主/竞争假设及风险，不边取数边找结论 |
| 等待 | 按事前测试/响应谓词观察；“感觉难做”不等于低风险 |
| 行动 | 只在授权流程内执行或纸上模拟；检查报价、数量、库存和条件，速度不替代合法性 |
| 监控 | 比较真实新增行为与原计划，细节与背景复核频率事前约定 |
| 亏损响应 | 记录失效、退出请求、无法成交及剩余风险，不移走止损等待回本 |
| 盈利响应 | 按冻结管理规则持有/退出；浮盈不认证规则正确 |
| 日终复盘 | 对照原卡审计信息、规则与执行，收益另列 |
| 定期检讨 | 查看全候选与失败分母，在新实验版本改规则，不改正在观察的旧版本 |

心理记录属于执行状态，不作为供需证据；书中的脑科学隐喻、成功比例和强烈行动措辞不升级为权限或统计结论。

## 行动序列训练

练习采用historical_reconstruction，教学样本是否曾见过写清楚。随机/预定选样规则先固定，包含未触发、失败与无法成交案例，不能只选教材赢家。

每一步：给出截至当时前缀与合法可得资料 → 冻结研究卡/哈希 → 明确支持反对、下一步预期与否定 → 按固定步长揭示后续 → 保存新增响应与结果 → 复盘。若因学习重做同案例，标training_replay和父run_id，保留首次记录；重做改善不能变成样本外或前瞻绩效。

同前缀复核可隐藏证券名称与未来收益，记录标注人、结构/事件分歧、漏报、耗时和裁决；多人同意也不证明预测价值。转折/边界修改须新版本，图形回标不能改旧决定。参见[训练模板](模板/行动序列训练.md)。

| 结果 | 过程合规 | 过程违规 |
|---|---|---|
| 盈利 | 保留事实，仍检验成本、分母和有效性 | 记录违规，收益不能消除缺陷 |
| 亏损 | 区分正常结果与规则/数据缺陷，保留失败 | 分别审计违规、输入与成交，不凭结果推断动机 |

合规亏损不自动说明执行错误；合规地执行未验证规则也不说明策略有效。每周按四类统计并保留未知/未成熟/未成交，不把它们硬塞到胜负。训练闭环提升可复核性，研究效力仍靠06/12的独立验证。
