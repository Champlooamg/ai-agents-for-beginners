# 合成威科夫流程验算

没有真实证券、收益或策略认证，只测试记录的时间与状态逻辑。D0等为相对观察时点。

| 时点 | 当时信息 | 合法记录 |
|---|---|---|
| D0 | 先登记支撑/阻力及竞争结构解释 | registered，边界版本冻结 |
| D1 | 强势表现出现，但转折需后续确认 | context_pending；当期价格事实可记录 |
| D2 | 回落开始，端点依赖仍不齐 | 临时Reaction事实，不认证已完成测试 |
| D3 | 背景与端点最后依赖到齐 | context_established；确认不倒签D1 |
| D4 | 满足预登记的LPS/BU测试谓词 | test_observed，同一缩量事实只一个evidence_id |
| D5 | 完整日线形成合法响应 | response_observed，最早订单晚于信息可得时间 |

若D4先触发原结构失效，保存invalidated，新解释用新ID。若等待期限到而无测试/响应，expired并保留错失/无响应样本。若D5同时触发相反条件而日内先后未知，path_ambiguous，按预登记保守政策处理。

Spring分支：先有支撑，再有下破、收回、测试与响应；不能在仅有下影线时认证。弱势分支：SOW出现后记录退出请求；当日新仓受可卖限制，保存未退出风险而非假设止损成交。
