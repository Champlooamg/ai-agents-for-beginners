# 威科夫中国市场研究体系 V0.6 落地验收报告

验收日期：2026-10-09，Asia/Shanghai。基础工作台承接 V0.5；本次审查 QuantMind 与 easy-tdx 两个用户上传包。

## 结论

V0.6随工作台隔离打包 easy-tdx 1.20.8 的 MIT 行情客户端源码，并接入显式点击的单股只读日线采集。采集上限800根，不复权；当天日线标为不完整。选定服务器和解码后的标准化返回行进入本机哈希留档，不冒充原始TCP报文。

QuantMind完整平台没有安装或执行；未启动任何模型、因子搜索、回测、模拟交易、券商、IM远程指令或后台数据抓取。easy-tdx的技术指标、缠论、筛选、回测和交易模块未接入。V0.4的TDX与InStock只读行情连接器保持原样。

绩效回测与真实Shadow仍是BLOCK；未得出任何策略有效性或实盘准入结论。

## 七包审查与决定

| 包 | 结论 | 接入范围 |
|---|---|---|
| PanWatch | 自托管AI监控平台，包含持仓、定时分析、告警、机会排序、纸面交易，并调用TradingAgents；运行依赖包括API模型、数据库和调度服务 | 只接受用户导出的报告做未验证留档 |
| TradingAgents-Astock | 多Agent辩论与交易评级输出；有特定未来函数保护测试，但特定函数测试不构成全数据链的历史PIT认证 | 不自动调用、不自动转研究卡；导出报告可留档 |
| TickFlow Stock Panel | 多市场筛选、指标、复合信号、参数优化和回测 | 不合并其信号、优化结果或回测绩效；报告可留档 |
| Global Stock Data | 面向美股为主的数据Skill，涉及SEC、CBOE、FINRA及宏观数据 | 不接入A股行情链；保留其逐源许可审查方法供参考 |
| Finance Quant Skills | 13个数据、回测、策略与QMT/MiniQMT交易相关Skills | 不全局安装/触发；报告可留档 |
| QuantMind | AI因子进化、模型训练/推理、Qlib回测、模拟交易、实盘适配和IM远程指令；AGPL-3.0 | 完整平台不安装，不将其输出送入威科夫判断链 |
| easy-tdx | 通达信TCP行情及指标、缠论、选股、回测和Web UI；MIT | 随包保留客户端源码，只接入只读日线采集 |

## 实际执行的验收

- `python -m unittest discover -s tests -v`：**52项通过**。
- 外部输出测试验证：哈希留档与导出、日期格式与未来日期/非法Unicode/超大文件拒绝、原文篡改检查，以及留档前后同一固定决策时刻的行情事实结果不变。
- TDX/InStock/easy-tdx离线连接器测试通过；它们使用合成响应，不代表真实供应商联网可用。
- Python模块编译检查通过，工作台内嵌JavaScript通过Node语法检查。
- 用干净临时目录执行演示数据初始化和doctor，本机完整性审计通过；gate仍为 descriptive AVAILABLE、backtest BLOCK、prospective Shadow BLOCK。
- 本环境禁止创建本地监听socket，HTTP端到端测试在socket初始化处被权限拒绝；真实供应商网络请求未执行。浏览器视觉检查未执行。

测试覆盖的是已列明实现性质，不证明无缺陷或投资有效。

## 数据与研究闸口

附件样本截至2026-10-08，1920行；不是独立留出。行情连接器仍未完成供应商完整性、授权、公司行动、历史状态/日历和PIT验收。外部文本的报告日期是用户填写值，账本时间是本机导入时间；SHA-256只证明保存文件的本地一致性。

| 铁律 | V0.6实现边界 |
