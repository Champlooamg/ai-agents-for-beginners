# V0.6.1 修复说明

本修复版针对 V0.6 代码审查提出的四项问题。它不改变威科夫事实计算口径，也不放宽研究或交易闸口。

## 修复内容

1. **日期统一为规范格式。** 分析截止日、冻结卡审计、候选到期日和数据连接器只接受 `YYYY-MM-DD`。日期先解析为日期对象再比较，`20261008` 等紧凑格式会被拒绝，不能再通过字符串排序把截止日后的行情带入事实前缀。
2. **随包 easy-tdx 不再查询外部发行元数据。** 内置源码直接声明版本 `1.20.8`；工作台可选安装依赖仍按 `pip install -e '.[easy-tdx]'` 安装 pandas 与 tzdata。连接器回归测试模拟行情客户端，不发起供应商网络请求。
3. **候选状态必须依赖新的前瞻观察。** 每次状态转换都要求在候选登记或上次决策之后采集/导入的新行情快照根、严格晚于上次观察的行情日期，并由支持证据引用新快照中该证券最新一根行情。提前导入后再登记、复用同一快照或只引用旧证据都会被拒绝。审计也会检查历史状态事件是否满足这些条件。
4. **候选去重不再依赖自由文本事件族。** 登记时新增结构起始日；工作台用证券、冻结协议、结构起始日、支撑/阻力边界和场景构成稳定候选键。修改事件族或结构名称不能重登记同一结构，同一结构ID也不能悄悄换边界。已接受和被拒绝的重复尝试都会追加到 `candidate_attempt` 账本表及导出包，并在工作台展示。

## 既有 V0.6 账本

旧账本不会被静默改写。已有候选状态事件若缺少新的快照根、更新日期或可追溯的新行情证据，V0.6.1 审计会报告对应问题；这些旧状态不能据此视作前瞻样本。保留原记录，并从新的行情快照开始观察。

## 验证与边界

- 单元测试：61 项通过。
- 安装验证：成功构建并安装 `0.6.1` wheel；无独立发行元数据时导入 vendored easy-tdx 并完成模拟连接器调用。
- easy-tdx：未访问真实行情服务器。
- HTTP 回环验收：当前执行沙箱禁止创建本地 socket（`PermissionError`），因此没有运行 HTTP 端到端烟测；相关路由只完成代码和单元级检查。
- 历史回测：`BLOCK`；前瞻 Shadow：`BLOCK`；生产权限与自动下单：关闭。
- 本修复不认证供应商数据完整性、历史 PIT、交易日历或策略有效性。
