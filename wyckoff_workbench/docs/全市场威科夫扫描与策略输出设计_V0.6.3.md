# 全市场威科夫扫描与策略输出设计（V0.6.3）

## 目标与当前交付边界

目标是覆盖沪、深、北普通A股，按威科夫理论形成可审计的候选观察与短、中期条件策略卡。唯一核心方法为威科夫；普通现货仅做多，W-WEAKNESS用于风险观察，不产生做空策略。

V0.6.3先打通全市场盘后数据入口：读取用户选择日期的通达信盘后包，解析包内可识别的普通A股，分别统计有价与无正收盘价代码；留存原始响应、SHA-256、覆盖计数和标准化收盘快照；提供单日上涨/下跌/平盘的描述统计。最少有价行阈值来自随包的数据源说明，只用于拒绝明显残缺包，不构成证券池完整性认证。

本版**不自动挑股、不输出买卖点或持仓建议、不生成短中期策略卡**。因为目前只有单日全市场包，证券状态、历史股票池、公司行动、复权、交易日历和场景触发谓词尚未通过验收。单日涨跌或成交额不能代替威科夫结构、测试与响应。

## 分层架构

| 层 | 责任 | 必须保留的口径 |
|---|---|---|
| 采集与原始留档 | 来源适配器只读取；保存原始字节、URL、采集时间、哈希和解析结果 | 禁止静默切换来源、拼接不同来源或把网络成功当作完整性认证 |
| 点时数据与证券池 | 交易日历、证券生效区间、上市/退市、ST、停复牌、板块、涨跌幅限制、公司行动及复权版本 | 同时记录事件日期与当时可得时间；历史扫描使用当日有效股票池，退市标的不能消失 |
| 威科夫背景与结构 | 先市场/行业复合体，再个股结构；记录区间边界、事件、测试、响应、保持、竞争解释 | 只用预先冻结的威科夫事件定义；缺依赖或顺序不明时保留unknown/path_ambiguous |
| 全市场候选扫描 | 按当日有效股票池执行冻结的W-BASE、W-LPS-BU、W-SPRING-TEST谓词 | 先过滤数据不合格证券，再输出状态与证据；不以未验证分数强行排先后 |
| 条件策略卡 | 为每个符合规则的候选给出可复算的条件计划 | 明确研究截止/决策时刻、规则版本、证据、进场触发、参考价或价带、失效点、退出条件、持有期限、风险预算、成交假设和限制项 |
| 复盘与验证 | 记录触发、未触发、失效、超时、未成交、滑点、费用和T+1库存批次 | 预登记样本、指标、试验预算和样本外区间；完成六道验证前不开放绩效结论 |

### 条件策略卡的最小字段

| 字段 | 定义 |
|---|---|
| 适用场景 | 仅已冻结的威科夫场景及版本，例如W-LPS-BU或W-SPRING-TEST |
| 观察截止与决策时刻 | 两者分开；决策只能依赖当时已采集且可得的数据 |
| 入场触发 | 测试及响应的精确谓词、确认时点和可交易的下一步条件；未触发时显示“等待”，不把触发价当成交价 |
| 计划入场价/价带 | 仅由冻结的价格参考方法生成；同时注明原始价/复权价、报价粒度、涨跌停和未成交风险 |
| 结构失效 | 对应候选的冻结边界/事件失效规则；明确盘中、收盘确认规则以及跳空越过时的处置 |
| 退出与减仓 | W-WEAKNESS等预登记风险条件、止损/结构退出和适用库存；A股T+1导致的当日不可卖限制需显式显示 |
| 持有期限 | 以交易日数表示的规则性观察上限/时间止损。短期和中期窗口分别预登记；没有通过样本外评估前标为“研究观察窗口”，不能称为预测或承诺 |
| 风险与仓位 | 最大账户风险预算、入场至失效点的风险距离、费用/滑点/成交约束；任一依赖unknown时不给仓位数 |
| 有效性状态 | `descriptive`、`candidate`、`triggered_unvalidated`、`out_of_sample_validated`等分开显示；只有最后状态可以展示经审计的研究绩效 |

目标价/盈亏比不从单日振幅或任意比例推导。只有点数图/区间测量方法完成理论裁决、版本冻结、事前登记和独立验证后才可启用；此前给出结构性退出规则，并显示目标价unknown。

## 数据与准入门槛

1. **行情源**：每日沪深北全市场快照；多日OHLCV、成交额、复权因子及公司行动需另选经过单独验收的历史源。不能用“当前前复权历史序列”伪造历史决策当时可见的价格。
2. **证券池**：每个交易日保存有效股票代码、交易所、板块、名称、上市/退市日期、风险警示和停复牌状态；与交易所官方清单或第二独立源对账，记录遗漏及差异。
3. **完整性**：检查重复代码/日期、行情块映射、OHLC、单位、成交额、前收盘、缺根、非交易日、除权日和数据修订。当前解析的代码前缀与来源最低行数门槛只能做基本筛查。
4. **威科夫规则**：W-BASE以及各场景的背景、区间边界、事件、测试、响应、失效、超时与出口顺序全部冻结并可复算；分析者间一致性先通过。
5. **历史评估**：点时证券池和数据验收通过后，按时间顺序隔离训练、验证、最终留出；纳入退市、停牌、涨跌停、T+1、费用、滑点、未成交、复权和组合风险；不得因结果调参后复用留出集。
6. **策略验证**：按项目现有六道门分别评估冗余、条件增量、消融、样本外、稳定性、复杂度收益。任何门未通过，卡片只能描述或列作未验证候选。

## 当前 API

- `POST /api/fetch/tdx-market`：用户明确给出一个日期；单次下载一个盘后包，无自动回退；解析后导入不可覆盖的数据快照并留存来源原文。
- `POST /api/market-overview`：只对上述市场包快照返回单日方向、交易所覆盖计数和阻断原因；`candidate_count`保持unknown，不把“未运行扫描”误写为“没有机会”。
- 原有单股采集、事实复算、人工研究卡、候选状态机保持原接口。

真实行情、历史PIT、回测和实盘权限状态均保持未认证或BLOCK；该文档不代表策略有效性结论。
