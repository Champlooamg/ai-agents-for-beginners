# 中国市场威科夫研究工作台 V0.6.3.0

本版把上传的 V0.2 研究规范变成可运行的本地工作台，并新增沪深北全市场盘后快照导入、覆盖率检查和单日方向观察。**当前可用的是描述性研究、冻结判断、候选跟踪与审计；自动选股、短中期策略输出、策略有效性、真实前瞻Shadow与绩效回测仍未通过。**

V0.6.3.0新增一键获取全市场TDX盘后包、普通A股代码/无价证券覆盖计数、原始响应留档及只读单日观察；原有单股事实、候选状态、账本及`previous_close`版本行为保持。架构与策略输出门槛见[全市场扫描与策略输出设计](docs/全市场威科夫扫描与策略输出设计_V0.6.3.md)。

## 启动

需要 Python 3.10 或更高版本；基础运行只用 Python 标准库。安装 easy-tdx 行情扩展：`pip install -e '.[easy-tdx]'`。

- Windows：解压完整压缩包，双击 `启动工作台.bat`。
- macOS / Linux：在解压目录运行 `sh start.sh`。
- 命令行：`python -m wyckoff_cn serve --open-browser`。

页面地址：`http://127.0.0.1:8765`。关闭时在启动窗口按 Ctrl+C。

首次启动会校验附件的原始行情哈希，载入宏柏新材、沪深300、上证指数各640根原始日线。附件数据截至2026-10-08，不会自动联网刷新；需要新行情时须到“数据源接入”明确点击获取。首次本机导入时间会另行记录。

## 你可以完成的工作

1. 导入UTF-8 CSV，检查重复、日期顺序、OHLC、量、时间和完整日线声明。
2. 查看有明确截止日期的量价事实；计算振幅、实体、影线、收盘位置、真实波幅、跳空、净进展、相对量、同日端点相对强弱。前收来源与使用口径可在事实表中核对。
3. 引用事实ID，填写主假设、竞争解释、证伪条件、待观察响应和独立风险，再冻结研究卡。
4. 登记W-LPS-BU / W-SPRING-TEST候选，冻结人工边界、测试/响应/否定条件与等待期限，追加状态观察。
5. 单列独立风险；通过CLI检查订单计划的时序、T+1批次库存、申报单位和资金约束。成交状态始终保留unknown。
6. 审计冻结记录，导出完整账本、全部候选、研究卡、原始CSV和运行报告。
7. 在“数据源接入”中按需获取 a-stock-data/TDX 日线包、InStock/Eastmoney单日行，或 easy-tdx 最近1至800根单股日线。只有点击按钮才请求网络；来源表示与标准化快照分别留档。
8. 在“全市场观察”中获取沪深北A股盘后包，查看有价/无价代码、交易所覆盖与单日涨跌计数。该页不进行标的排名或投资建议。
9. 在“外部分析留档”中保存外部工具报告原文；原文带哈希归档，不进入事实计算。

操作细节见 [使用说明](使用说明.md)，实现边界见 [落地验收报告](落地验收报告.md)。

## 关键边界

默认20根窗口是一个固定的事实描述协议，未经过收益优化，不能当作有效策略参数。自动阶段/事件识别、逐波端点、点数图、完整成交模拟和六道统计验证尚未实现。行情连接器均未通过供应商、完整性或历史PIT认证。easy-tdx连接器只取不复权日线；当天记录标为不完整，留档内容是解码后的标准化行而非原始TCP报文。

人工输入的解释、边界及规则不经语言模型生成，也不会自动升级为客观事实。程序检查引用和时序，文本谓词是否成立仍需人工复核。资料中的历史数据库、外部引擎、已配置凭据和“已安装技能”属于原资料的环境记录，本包没有据此假定这些资源现在可用。

本版不计算胜率、收益、收益排名或策略通过率。全市场盘后包只有一个交易日，不足以判断威科夫区间、测试与响应，也不能给出买点、卖点、持有期限或失效价。缺少PIT版本、真实历史状态/日历、来源验收、冻结基线、实验预登记、成熟标签和现实成交模型时，自动候选扫描、策略卡、回测和真实Shadow均保持BLOCK。禁止通过编辑开关宣称已验证。

## 检查与备份

```bash
python -m unittest discover -s tests -v
python -m wyckoff_cn doctor
python -m wyckoff_cn gate
python -m wyckoff_cn report --out reports/运行报告.md
python -m wyckoff_cn export --out reports/研究记录.zip
```

实际记录在 `data/`；备份或迁移时关闭程序后复制整个目录。导出的ZIP适合阅读与核对；本版恢复工作状态的方法是复制完整data目录，没有ZIP自动恢复接口。

七个附件包的源码审查、接入/不接入理由与SHA-256见 [附件包审查](integrations/附件包审查_2026-10-09.md)。QuantMind完整平台未安装；easy-tdx客户端源码随包隔离收录，仅提供可选只读行情接口，不启用其指标、缠论、选股、回测或交易功能。
