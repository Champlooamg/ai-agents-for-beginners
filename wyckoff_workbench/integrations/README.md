# 外部数据连接器接入记录

本目录记录用户上传的行情包和工具包的实际接入范围与准入决定。V0.4接入两个只读行情连接器；V0.5增加外部分析原文隔离留档；V0.6增加easy-tdx单股日线可选只读连接器。easy-tdx需显式安装扩展，并且只在“数据源接入”点击后连接行情服务器。

## 已接入

| 上游项目 | 实际接入功能 | 上游代码不接入的部分 |
|---|---|---|
| a-stock-data 3.10.1 | 按用户指定日期解析通达信日线数据包中的普通 A 股，并按项目声明记录成交量/成交额单位 | 其余 87 类行情、资讯、财务、行业等接口；全市场完整性和历史 PIT 验收 |
| InStock master | 只读调用其 `stock_zh_a_hist` 所用 Eastmoney 日线端点，取单股单日原始 OHLCV/金额 | 选股、指标、筹码、策略、回测、MySQL服务和所有自动交易能力 |
| easy-tdx 1.20.8 | 单股最近1–800根不复权日线；只在用户点击时取数；记录服务器与标准化行哈希 | 技术指标、缠论、选股、回测、Web UI、交易；原始TCP报文不保留 |

连接器来源观察会与标准化行情快照分开保存。快照进入原有行情事实管线；连接器不会生成威科夫结构判断、买卖信号或订单。来源响应表示、服务器/URL、采集时刻、证券/日期和 SHA-256 进入追加式账本；easy-tdx保存解码后的标准化行而非原始TCP报文。本机哈希审计只检查本地一致性，不构成上游真实性证明。

## 数据边界

- TDX 包仅解析用户明确选择的 1–5 个普通 A 股。只校验 ZIP、字段结构、证券代码/行情块索引、有限数和 OHLC 合法性；不声称整个市场覆盖完整。无指定证券行就报错，不静默切换来源。
- InStock 读取限制为沪深普通 A 股的一只、一天。数据行虽存在，`complete` 仍为 `unknown`，量额单位也保持来源原生未知，所以不能直接作为完整日频冻结判断的输入。
- easy-tdx按实际返回日期排序，严格限定在指定截止日内；当天根设为不完整。服务器返回字段不符、空行或非法OHLCV会报错，不能据此推断停牌或缺少成交。
- 两来源独立导入、独立核对；不自动拼接、平均或择优。任何日期均不补历史可得时间。两接口数据当前都不获得历史回测或真实 Shadow 资格。
- 网络错误、非交易日、未发布、字段变更或证券缺行都显式报错；不能据此推断停牌或缺少成交。
